Thoughtful Replies has been updated to v1.0.1! okuajub has joined the development team, the Ghost Jam jank has been cleaned up, and we've added a massive amount of new content. I can confidently say now that each session with the ghost will be different from the last! If you enjoy the ghost, please try running it multiple times to see more content.

Many of the new dialogues that were added were written for Aughost 2026. That's one of the reasons this update is coming so long after Ghost Jam! (Of course, it's now been a month since Aughost ended, but that delay is on me...)

This ghost has been a lot of fun to work on, and hopefully it will be just as fun to play with!

Changelog:

  • Added a large amount of dialogue. This includes more than 100 additional random dialogues, additional variants for some chains, several additional boot and close dialogues, and new additions to various word groups.

  • Added a chance for a postscript to display in some close dialogues.

  • Added compatibility with the plugin Spectre, including calibration and dialogues.

  • Fixed blinking on surfaces with eyes half closed.

  • Fixed an issue where homebody would not properly stay asleep after displaying all of the dialogue for that session.

  • Minor wording and formatting tweaks.

  • Updated to Aosora v1.0.12.
