The balloon Chicken Scratch is now available! It's a stationery-and-chicken themed balloon, made as an extra for Ghost Jam 2026.

This is a pretty odd one! It's keyed pretty strongly to the ghost it's made for, Thoughtful Replies. It only has one balloon size, but it also has extra balloon surfaces for a specific function in that ghost.

Also, it supports 3 fonts! We wanted a nice script font, and a more readable font... and then we decided to also add a more standard font to ensure good readability.

I'm quite happy with how this one came out. I had been dreading rendering the feather, but once I got into it I really enjoyed it! It's been a while since I worked with soft brushes, and I had a lot of fun.

Also, there's a certain part of this balloon that really makes me laugh. Please appreciate it.
