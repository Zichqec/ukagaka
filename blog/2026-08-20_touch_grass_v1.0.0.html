The Hydrate shell Touch Grass has been released! Touch grass anytime, anywhere, while staying hydrated. I made this for 8/20 Hydrate Shell Jam 2026.

This is a very simple shell compared to what I've done in previous years, and it's the only one I'm expecting to make. I've got a lot going on IRL right now and am exhausted, so I'm honestly surprised I managed to get this done at all.

I had some ideas for other variants I wanted to draw, but I just don't have it in me right now, so a super basic version is what we'll have for the moment. Maybe at some point I'll revisit this, but no guarantees.

That being said, there is a dressup included, which I think is pretty fun... but probably not what you expect :)
