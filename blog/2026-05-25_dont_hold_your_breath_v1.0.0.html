The ghost Don't Hold Your Breath is now available! This ghost is a collaboration with Galla that we made for Ghost Masquerade 8.

Galla also wrote an afterword for it that you can read for a little more behind the scenes information about what went into this ghost. They also made a review form! If you leave a review, it'll be displayed on Galla's website when they make this ghost's page.

For this separate release, a few bugs have been fixed, and the code has been polished up! (This would have come out a lot sooner, but I got sick right after Masquerade ended, so... it got pushed back, oops!)

Changelog:

  • Fixed the boot dialogue being possible to interrupt by double clicking the ghost.

  • Fixed a few missing pause tags (by switching to autopause).

  • The first scenario that ever plays is no longer fixed to a specific one. This was a measure we took specifically for Ghost Masquerade, so we've now removed it.

  • Improved scenario selection mechanic, scenarios are randomized properly as they were intended to be. (There is a nonoverlap effect so that the same scenario does not play twice in a row.)

  • Added links in the right click menu.

  • Added support for network updates.

  • Rearranged readme file and added content warnings (these were previously covered by the tags in the Masquerade guide ghost).

  • Removed collisions from the shell.

  • Improved various parts of the underlying code (no change in functionality, but it will be easier to add new content if we ever decide to do that).
